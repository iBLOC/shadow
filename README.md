# Shadow (影) — AI 用户分身系统

Shadow is a secure AI user avatar that runs on user devices (desktop or mobile), representing the user to execute daily tasks. All execution is **task-goal driven** — Shadow never acts proactively, only accepting task dispatch from Resonance.
