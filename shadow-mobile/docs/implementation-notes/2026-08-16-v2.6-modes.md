## 两种模式的设计

| 模式 | 路由 | 场景 |
|---|---|---|
| **Voice Assistant** (`/voice`) | mic → ASR → LLM → TTS → USB Audio/BT → shadow-esp32/speaker | 语音对话 |
| **Live Stream** (`/livestream`) | phone TTS → USB Audio/BT → shadow-esp32/speaker | 直播声卡,无数字人,纯语音 |

### shadow-esp32 在两种 mode 的角色

**shadow-esp32 仅做 USB 声卡**(v2.4 以来设计)——它接收 phone 发过来的 PCM 帧(通过 USB Audio OUT),通过 I²S TX → DAC → speaker 播放。shadow-esp32 在两种 mode 中的参与:
- Voice assistant:phone 做 ASR+LLM+TTS 全栈,shadow-esp32 只播
- Live stream:phone 做 TTS,shadow-esp32 只播

**shadow-esp32 完全不参与 ASR/LLM/TTS 逻辑**。phone 是唯一的智能体。

### 路由切换机制

`ShadowOutputRoute` enum + Riverpod state:

| OutputRoute | 行为 |
|---|---|
| `phoneSpeaker` | Android AudioManager default (built-in speaker) |
| `bluetoothHeadset` | phone 做 BT pairing,system routes to BT |
| `shadowEsp32` | `UsbAudioRouter.routeTo(shadowEsp32Id)` → phone 的 `AudioManager` 改到 USB Audio sink |

两种 mode 共享同一个路由选择。切换 mode 不影响路由。

## 验证

```bash
flutter pub get
flutter run -d <device>

# Voice Assistant mode (/):
# 1. Bottom nav → Chat
# 2. App bar top-right:USB icon → tap to route to shadow-esp32
# 3. Talk → LiteRT → TTS → shadow-esp32 USB Audio → speaker

# Live Stream mode (/livestream):
# 1. Bottom nav → Live
# 2. Text input → type "Hello world" → tap Play
# 3. TTS plays on shadow-esp32 USB Audio (if routed) or phone speaker

# Mode switch:
# 1. In Live Stream, tap top-right mic icon → switch to Voice Assistant
# 2. In Voice Assistant, tap top-right live_tv icon → switch to Live Stream
```
