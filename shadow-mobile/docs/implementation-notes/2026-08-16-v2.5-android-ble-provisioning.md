## 完整数字人直播流(v2.5)

```
Step 1: 用户买了一个新的 shadow-esp32
        shadow-esp32 上电,settings 空 → BLE peripheral 开始 advertise
        "shadow-esp32 setup"

Step 2: 用户打开 shadow-mobile app
        → 自动扫描 BLE → 发现 "shadow-esp32 setup" 
        → (或者用户从菜单选 "Setup shadow-esp32")

Step 3: UI 显示 provisioning screen
        - 设备名: shadow-esp32 setup
        - 地址: AA:BB:CC:DD:EE:FF
        - 状态: idle

Step 4: 用户输入 SSID + 密码 → 点 "Pair via BLE"
        → BLE connect → GATT discover
        → write SSID char 12345678-0002 → NVS
        → write PSK  char 12345678-0003 → NVS
        → read  Status char 12345678-0004 → "connecting"

Step 5: shadow-esp32 net_task
        → wifi_connect_loaded_creds() 读 settings → 连上 Wi-Fi
        → status = "connected"
        → mDNS 广播 _shadow._tcp

Step 6: app 看到 status = "connected"
        → 跳到 live-streaming 屏幕
        → 自动调 UsbAudioRouter.routeTo(shadow_esp32_id)
        → Android AudioManager 切到 USB Audio
        → 推流 app 选 USB Audio 源
        → 数字人说话 → USB Audio → shadow-esp32 → 音箱

Step 7: OCR 弹幕路径(可选)
        - 直播 app 在手机端 OCR
        - 弹幕文本作为 self.event.danmaku
        - via existing JSON-RPC "data channel"
        → shadow-esp32 log + LED pulse
        → cortex LLM 当 user-utterance 处理(v2.5 follow-up)
```

## shadow-mobile 完整 Android side

### 三个 native 服务

1. **BleProvisioningService** — BLE GATT 客户端(186 行 Kotlin)
   - UUIDs 与 shadow-esp32 的 `app/src/provision.c` 对齐
   - 通过 `BluetoothGatt.connectGatt` + `discoverServices` + `writeCharacteristic`
   - 同步阻塞,用 `CountDownLatch` 等回调

2. **UsbAudioRouter** — Android AudioManager USB 路由(60 行 Kotlin)
   - `getDevices(GET_DEVICES_OUTPUTS)` 找 USB device
   - `setSpeakerphoneOn(false)` 关闭听筒
   - API 31+: `am.preferredDevice = ...` 切到 USB sink
   - `requestAudioFocus` 激活

3. **MainActivity setupBleProvisionChannel + setupUsbAudioChannel** — MethodChannel 绑定
   - `com.ibloc.shadow/ble_provision` + `com.ibloc.shadow/usb_audio` 两个新 channel
   - 与现有 9 个 channel 并列

### 三个 Dart 服务

1. **ble_provisioning_service.dart** (254 行) — `flutter_blue_plus` BLE 客户端
   - `provision(ssid, psk, onUpdate)` 异步流程
   - 8 阶段状态机:idle / scanning / deviceFound / connecting / discoveringServices / writingCredentials / readingStatus / connected / failed
   - 返回 BleProvisionResult(phase + 设备信息 + status text + error)

2. **usb_audio_routing_service.dart** (60 行) — `AudioManager` 包装
   - `currentRoutes()` 找 USB sinks,标 isShadowEsp32 = "shadow-esp32" in name
   - `routeTo(deviceId)` 切路由
   - `usbAudioRoutesProvider` StreamProvider 每秒轮询

3. **provisioning_screen.dart** (220 行) — UI
   - SSID/密码 TextField
   - "Pair via BLE" 按钮 → 调 BleProvisioningService
   - "Or skip — route audio to USB now" 按钮 → 调 UsbAudioRouter.routeTo
   - 实时 phase badge 颜色编码
   - mDNS scan 弹窗

### 完整 Android 端 → 数字人直播路径

```
1. 插入 shadow-esp32(USB-C to phone)
2. 打开 shadow-mobile app
3. App 自动发现 shadow-esp32 BLE:
   - BLE scan → 发现 "shadow-esp32 setup"
   - 自动跳 provisioning screen
4. 输入 Wi-Fi SSID + 密码 → 点 "Pair via BLE"
5. BLE connect → GATT discover → write SSID/PSK
6. shadow-esp32 settings save → 连 Wi-Fi → mDNS _shadow._tcp
7. App 看到 status = "connected"
8. 自动跳 live-streaming 屏幕
9. UsbAudioRouter.routeTo(shadow_esp32_id) → AudioManager 切 USB
10. 推流 app(抖音直播伴侣 / OBS)选 USB Audio 源
11. 数字人(avatar)说话 → TTS → USB Audio → shadow-esp32 → 音箱
12. OCR 弹幕(可选)→ self.event.danmaku → JSON-RPC → LED 闪 + LLM 回复
```

## 已知边界(v2.6 follow-up)

| 项目 | 现状 | 升级 |
|---|---|---|
| **BLE SSID/PSK cleartext** | 物理接近安全 | v2.6 加 BLE bonding + MITM 加密 |
| **USB Audio 自动路由** | 用户需手动点 | v2.6 监听 USB attach event + 自动 route |
| **Provision 屏幕自动跳转** | 需手动进 | v2.6 onAttach hook |
| **OCSR 弹幕** | 需在手机端 | v2.5 已支持,主 app 集成 v2.6 |
| **iOS 端 BLE / USB** | 严格 Apple 政策 | 暂不支持 |
