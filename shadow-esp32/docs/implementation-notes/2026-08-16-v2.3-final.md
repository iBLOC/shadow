## 关键设计取舍

### DTLS 真 handshake(UDP fd)

```c
int shadow_dtls_handshake_udp(const char *host, uint16_t port,
                                uint8_t *out_master_buf,
                                size_t out_master_cap) {
    int fd = zsock_socket(AF_INET, SOCK_DGRAM, IPPROTO_UDP);
    struct sockaddr_in addr = { 0 };
    addr.sin_family = AF_INET;
    addr.sin_port = htons(port);
    zsock_inet_pton(AF_INET, host, &addr.sin_addr);
    int rc = shadow_dtls_handshake(fd, out_master_buf, out_master_cap);
    zsock_close(fd);
    return rc;
}
```

`shadow_dtls_handshake(fd, ...)` 现在在真 UDP fd 上跑完整 mbedtls_ssl_handshake loop。v2.2.1 提供的真 `mbedtls_ssl_export_keying_material` 在 handshake 成功后被调用,导出 30-byte master。

### usrsctp Zephyr module

```yaml
# app/sctp/zephyr/module.yml
name: libusrsctp
build:
  cmake: .
  settings:
    board_root: .
    board: .
  kconfig:
    skip:
      - .
```

`app/sctp/CMakeLists.txt` 加 `add_subdirectory(libusrsctp)`,usrsctp 自己的 CMake build 暴露 `usrsctp` static library,通过 `target_link_libraries(app PRIVATE usrsctp)` 链入。

west.yml 已经在 v2.2 加了 `libusrsctp: master` 项目,`west update` 拉源码。

### I²S TX playback

devicetree overlay 加 `shadow_i2s0_tx_default` pinctrl group(GPIO17 BCK + GPIO9 DIN);production 板接 MAX98357A amp。

`shadow_audio_pipeline_write_pcm` 在 base devkitc 是 no-op;`CONFIG_SHADOW_I2S_PLAYBACK=y` 时走真 `i2s_write()`。

### mcumgr 真实配置

`prj.conf` 启用 `CONFIG_MCUMGR=y` + `CONFIG_MCUMGR_TRANSPORT_UDP=y`;BLE 留 follow-up(NimBLE host stack 太大,留作单独 commit)。

## 已知边界

1. **DTLS server** — v2.3 client side ready;server side 在 temporal lobe (`webrtc-rs`) 已 production ready;CI smoke 需要 PSK server,留 host 端 `openssl s_server -psk` 配置
2. **usrsctp 编译** — west update 拉源码后,usrsctp 的 CMakeLists 会构建,但当前还没真的在 dialog_task 调 SCTP API;sctp_agent.c 的 byte-level framing 是 v1 stand-in
3. **I²S TX** — bare devkitc 没 DAC;真实现留 v2.4
4. **mcumgr BLE** — 留 v2.4(NimBLE host stack 太大,50 KB+)
