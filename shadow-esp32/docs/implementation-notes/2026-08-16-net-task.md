## net_task v1 设计

### 职责

| 任务 | 实现 |
|---|---|
| **Wi-Fi 连接** | `net_mgmt(NET_REQUEST_WIFI_CONNECT, ...)` with PSK 安全; `CONFIG_SHADOW_WIFI_SSID` / `CONFIG_SHADOW_WIFI_PSK` Kconfig-driven |
| **事件回调** | `NET_EVENT_WIFI_CONNECT_RESULT` → `k_sem_give(&shadow_net_wifi_up)`;<br>`NET_EVENT_WIFI_DISCONNECT_RESULT` → 5s backoff 重连 |
| **mDNS** | `CONFIG_MDNS_RESPONDER=y` 由 Zephyr mainline 自带服务注册;**无 C 代码** — TXT 记录通过 devicetree/Kconfig 静态注入 |
| **线程模型** | 一个 K_THREAD(stack 4 KiB, prio 6);Wi-Fi 事件到达前 `k_sleep(K_FOREVER)`,全事件驱动 |
| **重连** | `K_WORK_DELAYABLE_DEFINE(wifi_reconnect_work, 5s)` + `wifi_mgmt_handler` 在 disconnect 时 schedule |

### 关键 API 暴露

```c
/* tasks.h — 公共信号 */
extern struct k_sem shadow_net_wifi_up;

/* 等待 Wi-Fi 就绪后,dialog_task 启动 WebSocket signaling 客户端 */
k_sem_take(&shadow_net_wifi_up, K_FOREVER);
```

### 关键 Kconfig(在 `app/prj.conf`)

```kconfig
# 这些必须在用户 overlay 或 prj.user.conf 中设置
# CONFIG_SHADOW_WIFI_SSID="your-ssid"
# CONFIG_SHADOW_WIFI_PSK="your-password"
```

未配置时 net_task 启动后会输出 warning 并保持 offline,不 panic。

## 与其他任务的接线

| Task | 依赖 net_task 提供的什么 |
|---|---|
| `dialog_task` | `shadow_net_wifi_up` 信号 → 之后才打开 WebRTC signaling WebSocket(#3 工作) |
| `io_task` | 无直接依赖(io_task 是本地 GPIO,不联网) |
| `led_task` | 无直接依赖(状态指示器由 dialog_task 喂) |
| cortex webrtc route | 无直接调用 — ESP32 ↔ cortex 是 Wi-Fi ↔ WebSocket,与 cortex 内部 API 解耦 |

## Out of Scope(后续 commit)

1. **WebSocket signaling 客户端** — ADR-0002 v2 §后续动作 #3 (`dialog_task` v1 工作, 6-7 周)
2. **DNS-SD browse 找 cortex** — 当前用 Kconfig 提供 cortex host/port;后续可加 mDNS browse `_cortex._tcp`
3. **TLS / wss://** — v1 用 ws://;cortex 默认无 TLS;未来切 wss:// 需要 mbedtls client profile
4. **Wi-Fi 自动扫描 + 智能选 AP** — 当前只支持单 SSID;**Provisioning** 是另一个未来工作

## 已知边界

1. **本机无 Zephyr SDK / west** — 验证只能在 devcontainer (`zephyrprojectrtos/zephyr-build:0.16-3`) 或 CI 上跑 `west build -b esp32s3_devkitc app`
2. **`CONFIG_MDNS_SERVICE_NAME`** — Zephyr 自动生成 `_shadow._tcp.local.` 公告;实例名 `shadow-esp32` 通过 host name 实现(后续 commit 可在 devicetree 覆盖)
3. **首次 Wi-Fi connect 在 work handler 中跑** — 这意味着它在 **系统线程**(system workqueue)而不是 net_task 线程执行;避免 net_task 栈被 wifi_mgmt 内部调用栈占用
4. **Wi-Fi 凭据在 Kconfig 中明文** — 生产环境需要 NVS 加密存储(后续 commit)
