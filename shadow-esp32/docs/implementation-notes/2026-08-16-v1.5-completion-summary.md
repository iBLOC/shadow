## 已知边界(累积)

1. **DTLS v1 用 deterministic placeholder master key** — 真实 mbedtls_ssl_export_keying_material 留 v1.6
2. **ICE-lite v1 收集 host candidates 但不答 STUN binding** — 留 v1.7
3. **SCTP v1 只做 byte-level framing,无 usrsctp 集成** — 留 v1.8
4. **WS2812 真 RGB 留 v2.2** — 需要 libled 或 ws2812 driver
5. **I²C sensor v1 框架已就位但未实现** — 真实 sensor read 留 v2.2
6. **OTA v1 注释 + Kconfig** — 实际 mcuboot + mcumgr 留 v2.2
7. **本机无 Zephyr SDK** — 所有 v1.5 代码在 CI 验证(west build)
